# Tienda de Productos

La aplicación consiste en una tienda de productos desarrollada con React, Bootstrap y Firebase. Incluye manejo de componentes, carrito de compras, formularios, autenticación, almacenamiento de archivos y generación de una aplicación Android mediante Cordova.

Sitio desplegado en Netlify: https://prog-componentes-examenfinal-tienda.netlify.app

Repositorio de GitHub: https://github.com/ceciliaasanchezdv/2026_Programacion-Componentes.git

## Funcionalidades

- Listado dinámico de productos utilizando `map()`.
- Comunicación entre componentes padre e hijo mediante props y callbacks.
- Carrito de compras utilizando `state` y `this.setState()`.
- Agregar y eliminar productos del carrito.
- Cálculo automático del total del carrito.
- Formulario controlado en React.
- Validación de nombre y correo mediante Simple React Validator.
- Almacenamiento de datos en Firebase Firestore.
- Registro e inicio de sesión mediante Firebase Authentication.
- Subida de archivos mediante Firebase Storage.
- Visualización del progreso de subida.
- Interfaz desarrollada con Bootstrap.
- Conversión del proyecto React a aplicación Android mediante Cordova.
- Generación, firma y prueba del APK en un emulador Android.

## Tecnologías utilizadas
